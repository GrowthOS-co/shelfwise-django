# Shelfwise

The web shop of a small independent bookshop: browse the catalogue, add books
to a cart, check out with a name and shipping address, and see the order. The
shop owner sees every order and marks it shipped. There is no login and no
payment step: placing an order records it.

Built with Django, the Django ORM on SQLite, and Django templates with one
plain CSS file.

## Getting started

Needs Python 3.12 or newer.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python manage.py migrate   # creates shelfwise.db and its tables
.venv/bin/python manage.py seed      # loads sample data
.venv/bin/python manage.py runserver
```

Open [http://localhost:8000](http://localhost:8000).

`manage.py seed` can be run again at any time: it replaces everything in the
database with the sample shop.

## How it works

- **Books** have a title, author, ISBN, genre (Fiction, Mystery, Science or
  History), year, description, price and how many are in stock. Money is
  stored as whole cents.
- A **cart** is created on the first add to cart; the browser keeps its token
  in the `cart_token` cookie. A cart has one line per book, and a line's
  quantity can never go above the book's stock. The cart total uses each
  book's current price.
- **Placing an order** turns the cart into an order in one step: it copies
  each book's title and price onto the order, takes the quantities out of
  stock and empties the cart. If any line is now over the stock, nothing
  changes.
- An order is `placed` or `shipped`; only a placed order can be marked shipped.
- When a rule refuses something (not enough stock, an empty cart), the message
  is shown on the page you were on.

| Path                                  | What it is                                   |
| ------------------------------------- | -------------------------------------------- |
| `shop/models.py`                      | the tables and the cart and order rules      |
| `shop/migrations/`                    | migrations, generated by `makemigrations`    |
| `shop/management/commands/seed.py`    | the sample shop                              |
| `shop/forms.py`                       | add to cart, cart line and checkout forms    |
| `shop/views.py`, `shop/urls.py`       | pages and form actions                       |
| `shop/context_processors.py`          | the cart count in the nav bar                |
| `shop/tests.py`                       | tests                                        |
| `templates/`, `static/shelfwise.css`  | the HTML and its styles                      |
| `config/`                             | project settings                             |

## Changing the database

Edit `shop/models.py`, then:

```bash
.venv/bin/python manage.py makemigrations   # writes a new migration into shop/migrations/
.venv/bin/python manage.py migrate
```

## Tests

```bash
.venv/bin/python manage.py test
```
